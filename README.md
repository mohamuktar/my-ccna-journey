# My CCNA Journey

This repository documents my complete journey through the **Cisco CCNA (200-301)** certification, following [Jeremy's IT Lab](https://www.youtube.com/@JeremysITLab) free CCNA course. Every lesson from the official playlist has its own folder containing my personal notes and the Packet Tracer lab for that day. The goal is to learn networking deeply, practice hands-on in every lesson, and build a public record of my progress along the way.

## Objectives

- Study Jeremy's IT Lab CCNA course
- Build practical networking skills
- Complete Packet Tracer labs
- Prepare for Cisco CCNA (200-301)
- Build a public networking portfolio

## Repository Structure

Each lesson folder is numbered to match its day in the course (e.g. `01-network-devices`, `02-interfaces-and-cables`) and contains exactly two files:

| File | Purpose |
|------|---------|
| `notes.md` | My personal study notes for the lesson — key concepts, IOS commands, diagrams, and takeaways |
| `lab.pkt` | The Cisco Packet Tracer lab file where I practice the lesson's configuration hands-on |
